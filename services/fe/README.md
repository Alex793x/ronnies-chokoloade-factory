# ronnies-chokoloade-factory — `fe` service

> Verdens bedste italienske chokolade is

A Ramboll **Frontend (React)** service (`fe:react`), owned by the
**Energy** department (Adam Lagoda, Alex Holmberg, Allan Zimmermann, 7AI, Elina K.).
Generated by the Ramboll Developer Platform (Keel) from the `fe-react` service
blueprint — **green from birth**: it installs, type-checks, builds and passes
its component + fast-check property tests on the very first commit.

_Bright ideas. Sustainable change._

---

## Where am I?

This service lives at **`services/fe/`** inside the `ronnies-chokoloade-factory`
monolith. Run every command below from this directory. CI, CODEOWNERS and
governance are owned by the repository root — the smart pipeline
(`.github/workflows/ci.yml` at the root) runs this service's checks only when
`services/fe/**` or a shared path changes. The full service index is in
`keel.services.json` at the root.


## What is this?

React 19 + TypeScript on Vite, tested with Vitest, Testing Library and
**fast-check**. The shell component is `src/App.tsx`; presentational logic
lives in pure `src/lib/` helpers (see `classNames.ts`) so it stays
property-testable. Dependency versions are pinned to the platform's known-good
set.

## Quickstart

```bash
npm install        # first commit ships no lockfile; commit package-lock.json,
                   # then use `npm ci` from there on
npm run dev        # dev server (Vite, HMR)
npm test           # Vitest: component + fast-check property tests
npm run typecheck  # tsc --noEmit (strict)
npm run build      # production bundle in dist/
```

## CI

These commands are wired into the root smart pipeline per service — no
`.github/` directory exists at this level on purpose.


## Testing standard

Every pure helper in `src/lib/` ships with **fast-check property tests** beside
the example tests (`src/lib/*.test.ts`): an oracle property, cleanliness
invariants and idempotence for `cx`. Components get Testing Library smoke tests
(`src/App.test.tsx`).
