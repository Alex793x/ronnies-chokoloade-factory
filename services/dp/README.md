## Where am I?

This service lives at **`services/dp/`** inside the `ronnies-chokoloade-factory`
monolith. Run every command below from this directory. CI, CODEOWNERS and
governance are owned by the repository root — the smart pipeline
(`.github/workflows/ci.yml` at the root) runs this service's checks only when
`services/dp/**` or a shared path changes. The full service index is in
`keel.services.json` at the root.


## What is this?

A data pipeline on the Ramboll Python golden path. The seeded first stage in
`src/ronnies_chokoloade_factory/pipeline.py` is a pure records→normalised-records
transform (snake_case keys, whitespace-sane values, deterministic collision
handling) plus an order-stable valid/rework fork. Grow the pipeline by adding
further pure stages and composing them — purity is what keeps every stage
property-testable.

## Quickstart

```bash
# 1. Set up an environment
python -m venv .venv && source .venv/bin/activate

# 2. Install the dev toolchain
pip install -e ".[dev]"

# 3. Run the tests (smoke + Hypothesis property tests)
pytest
```

## Quality gates

The same three gates run locally and in CI:

```bash
pytest             # test  — smoke + property tests
ruff check . && black --check .
mypy .             # validate — lint, format, strict types
python -m build    # build — wheel + sdist (pip install build)
```

These commands are wired into the root smart pipeline per service — no
`.github/` directory exists at this level on purpose.


## Testing standard

Every pure public function ships with at least one **Hypothesis property test**
(`tests/test_properties.py`) beside the example-based smoke tests
(`tests/test_smoke.py`): normalisation is idempotent (the round-trip property),
keys keep an exact charset invariant, and the partition fork is lossless.
